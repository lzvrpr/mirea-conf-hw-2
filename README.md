# Этап 5. Визуализация

Практическая работа №2, вариант №16, этап 5.
Реализация: Python 3.9+ и aiohttp — сеть асинхронная.

## 1. Общее описание

Приложение строит граф зависимостей пакета и показывает его деревом,
диаграммой Mermaid и SVG-картинкой. Ввод-вывод асинхронный: метаданные
пакетов запрашиваются через `aiohttp`, дети одного узла строятся
параллельно через `asyncio.gather`, чтение и запись файлов уходят в
отдельный поток через `asyncio.to_thread`.

Что уже работает:

- разбор и проверка параметров командной строки, отладочный вывод;
- загрузка метаданных из PyPI, разбор строк PEP 508 без сторонних библиотек;
- обход в глубину с ограничением глубины и распознаванием циклов;
- параллельные запросы: дети одного узла запрашиваются одновременно;
- дедупликация: один пакет в разных ветках даёт один HTTP-запрос;
- обратные зависимости по тестовому репозиторию;
- вывод деревом ASCII, диаграммой Mermaid и SVG-изображением.

Асинхронность только там, где есть ввод-вывод. Разбор параметров, разбор
PEP 508, печать и расчёт раскладки SVG — обычный синхронный код: они
считают, а не ждут, и `async` им ничего не даёт.

Осознанные ограничения:

- aiohttp — сторонняя библиотека, её нужно установить; без сети работает
  только режим `test`;
- на быстром канале параллельность почти не видна: накладные расходы
  `aiohttp` (около 0,15 с на импорт) сравнимы с выигрышем на маленьких
  графах. Выигрыш заметен на медленной сети и десятках запросов;
- маркеры окружения не вычисляются, extras в граф не входят;
- обратные зависимости строятся только по тестовому репозиторию;
- кэш метаданных живёт в памяти процесса.

## 2. Функции и настройки

Параметры командной строки:

- `--package ИМЯ` — имя анализируемого пакета, обязательный;
- `--repo URL` — база репозитория, например `https://pypi.org/pypi`;
- `--repo-file ПУТЬ` — файл тестового репозитория для режима `test`;
- `--mode {real,test}` — источник зависимостей;
- `--depth N` — максимальная глубина обхода, 1…20, по умолчанию 3;
- `--tree` — печатать дерево с ветками ASCII;
- `--reverse` — обратные зависимости (только режим `test`);
- `--mermaid` — печатать диаграмму Mermaid;
- `--image PATH` — сохранить SVG-изображение графа.

Состав файлов:

- `main.py` — точка входа: `asyncio.run`, сессия `aiohttp`, обход, печать;
- `src/config.py` — параметры командной строки и их проверка;
- `src/pypi.py` — асинхронный клиент репозитория: `fetch_metadata`,
  `PyPiProvider` с кэшем и дедупликацией одновременных запросов;
- `src/requirement.py` — разбор строк PEP 508;
- `src/graph.py` — узел, граф и асинхронный `build_tree` с `gather`;
- `src/test_repo.py` — чтение файла тестового репозитория через `to_thread`;
- `src/report.py` — текстовый вывод;
- `src/mermaid.py` — диаграмма Mermaid;
- `src/svg.py` — раскладка и сборка SVG;
- `tests/` — тесты, 100 штук; сеть подменяется фейковой сессией;
- `examples/` — тестовые репозитории.

Коды выхода: `0` — успех, `2` — ошибка в параметрах, `3` — ошибка
репозитория или файла.

## 3. Сборка и запуск тестов

```
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

Запуск:

```
./run.sh --package requests --repo https://pypi.org/pypi --depth 2 --tree
```

Тесты:

```
python3 -m unittest discover -s tests
```

Ожидаемый результат: `Ran 100 tests` и `OK`. Сеть в тестах не используется:
подменяется фейковая сессия `aiohttp`.

## 5. Сравнение с pipdeptree

На `requests` наш граф совпадает с `pipdeptree`: `certifi`,
`charset-normalizer`, `idna`, `urllib3`. На `flask` у нас на одну
зависимость больше — `importlib-metadata`.

Причина: у `Flask` в метаданных стоит
`importlib-metadata>=3.6.0; python_version < "3.10"`. Мы маркер не
вычисляем и показываем зависимость всегда, а pip вычисляет его на локальном
Python 3.14, где условие ложно. Остальные расхождения — установленные
версии против спецификаторов, регистр имён и повторы пакета в разных ветках
дерева.
